## When to use

Use this skill when the user asks for project analysis, architecture orientation, or implementation planning.

## Workflow

1. Use `ls` and `read` to inspect repository structure and core docs.
2. Identify key modules, entry points, and test locations.
3. Summarize constraints and conventions that affect implementation.
4. Propose a short execution plan with concrete file targets.

## Output checklist

- Project purpose and major areas
- Important constraints and conventions
- Recommended implementation plan
- Optional validation steps
